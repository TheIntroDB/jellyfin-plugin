TheIntroDB

Segment data (intro, recap, credits, preview) is fetched from TheIntroDB API using each item's TMDB or IMDB ID. Segments are not loaded when you press play—run Dashboard → Scheduled Tasks → Media segment scan to populate them. Items need TMDB/IMDB IDs (e.g. from metadata) for the plugin to find segments.

Optional Bearer token; when set, your pending and accepted submissions are weighted higher in results.
